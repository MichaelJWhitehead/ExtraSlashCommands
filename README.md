# Installation:
- Download the folder as a zip file
- Extract and make sure that the folder is called `ExtraSlashCommands`
- Put folder into the addons folder

# Commands added
## Edit mode:
- /em
- /edit
- /editmode
## Reload
- /rl
## Cooldown manager
- /cd
- /cooldown
## Countdown
- /pull {number}
## Keystone Loot window
- /wl
- /wishlist
## Great Vault window
- /gv
- /vault
## Celsius to Fahrenheit converter(And vice/versa)
- /temp {number}{unit}
## Midnight season 2 delve boss
- /delve
